# RentIt — Полное техническое задание (актуальная версия)

> P2P маркетплейс аренды инструментов между соседями
> Стек: React 18 + TypeScript + Vite + Supabase + Stripe
> Последнее обновление: март 2026

---

## 0. Стратегическое позиционирование

**Ниша:** инструменты и строительное оборудование (не универсальный маркетплейс)
**Слоган:** "Your neighbor's garage, on demand"
**Субслоган:** "Rent professional tools from people nearby — cheaper than buying, ready in minutes"
**Целевой рынок:** Бельгия → DIY-энтузиасты, мелкие подрядчики, новосёлы
**Монетизация:**
- Комиссия платформы: **12%** от суммы аренды (поднять до 15% при росте трафика)
- Страховка: **€3/день** с каждой аренды (покрытие ущерба до €500)
- Pro-подписка: **€9.99/мес** — 0% комиссии (v2)
- B2B Desk: **€49-149/мес** — для магазинов аренды инструментов (v2)

## 3. База данных — актуальная SQL схема

### Таблица: users

```sql
CREATE TABLE public.users (
  id                uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  full_name         text NOT NULL DEFAULT '',
  role              text NOT NULL DEFAULT 'user',  -- 'user' | 'admin'
  phone             text,
  phone_verified    boolean NOT NULL DEFAULT false,
  avatar_url        text,
  village           text,
  referral_code     text UNIQUE,
  referred_by       uuid REFERENCES public.users(id),
  rating_as_owner   numeric(3,2),
  rating_as_renter  numeric(3,2),
  created_at        timestamptz NOT NULL DEFAULT now()
);

CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS trigger AS $$
BEGIN
  INSERT INTO public.users (id, full_name, referral_code)
  VALUES (
    new.id,
    new.raw_user_meta_data->>'full_name',
    upper(substring(md5(random()::text), 1, 6))
  );
  RETURN new;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```

### Таблица: items

```sql
CREATE TABLE public.items (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  owner_id      uuid NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  title         text NOT NULL,
  description   text,
  category      text NOT NULL,
  -- power_tools | hand_tools | garden | construction | cleaning | measuring
  condition     text NOT NULL DEFAULT 'good', -- new | like_new | good | fair
  price_per_day numeric(10,2) NOT NULL,
  deposit       numeric(10,2) NOT NULL DEFAULT 0,
  photos        text[] NOT NULL DEFAULT '{}',
  lat           float8,
  lng           float8,
  address       text,
  available     boolean NOT NULL DEFAULT true,
  created_at    timestamptz NOT NULL DEFAULT now()
);
```

### Enum: booking_status

```sql
CREATE TYPE booking_status AS ENUM (
  'pending_payment',
  'confirmed',
  'active',
  'completed',
  'cancelled',
  'disputed'
);
```

### Таблица: bookings

```sql
CREATE TABLE public.bookings (
  id                        uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  item_id                   uuid NOT NULL REFERENCES public.items(id) ON DELETE CASCADE,
  renter_id                 uuid NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  start_date                date NOT NULL,
  end_date                  date NOT NULL,
  total_days                int NOT NULL GENERATED ALWAYS AS (end_date - start_date + 1) STORED,
  total_price               numeric(10,2) NOT NULL,   -- сумма аренды без депозита и страховки
  deposit_amount            numeric(10,2) NOT NULL DEFAULT 0,
  insurance_amount          numeric(10,2) NOT NULL DEFAULT 0,  -- €3/день
  platform_fee              numeric(10,2) NOT NULL DEFAULT 0,  -- 12% от total_price
  deposit_returned          boolean NOT NULL DEFAULT false,
  status                    booking_status NOT NULL DEFAULT 'pending_payment',
  stripe_payment_intent_id  text,
  amount_paid               int,  -- в центах
  created_at                timestamptz NOT NULL DEFAULT now(),
  CHECK (end_date >= start_date)
);
```

### Таблица: payments

```sql
CREATE TABLE public.payments (
  id                        uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  booking_id                uuid NOT NULL REFERENCES public.bookings(id) ON DELETE CASCADE,
  stripe_payment_intent_id  text NOT NULL UNIQUE,
  amount                    int NOT NULL,          -- центы: аренда + депозит + страховка
  rental_amount             int NOT NULL,          -- центы
  deposit_amount            int NOT NULL,          -- центы
  platform_fee              int NOT NULL,          -- центы (12%)
  insurance_amount          int NOT NULL DEFAULT 0, -- центы (€3/день)
  status                    text NOT NULL DEFAULT 'pending'
                            CHECK (status IN ('pending','succeeded','failed','refunded')),
  created_at                timestamptz NOT NULL DEFAULT now()
);
```

### Таблица: reviews

```sql
CREATE TABLE public.reviews (

  item_id       uuid REFERENCES public.items(id),
  review_type   text NOT NULL, -- item | owner | renter
```

### RPC: get_booked_dates

```sql
CREATE OR REPLACE FUNCTION get_booked_dates(p_item_id uuid)
RETURNS TABLE(start_date date, end_date date) AS $$
  SELECT start_date, end_date
  FROM bookings
  WHERE item_id = p_item_id
    AND status IN ('confirmed', 'active', 'pending_payment');
$$ LANGUAGE sql STABLE;
```

### RLS политики

```sql
ALTER TABLE public.users    ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.items    ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.bookings ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.payments ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.reviews  ENABLE ROW LEVEL SECURITY;

CREATE POLICY "users_select" ON public.users FOR SELECT USING (true);
CREATE POLICY "users_update" ON public.users FOR UPDATE USING (auth.uid() = id);

CREATE POLICY "items_select" ON public.items FOR SELECT USING (true);
CREATE POLICY "items_insert" ON public.items FOR INSERT WITH CHECK (auth.uid() = owner_id);
CREATE POLICY "items_update" ON public.items FOR UPDATE USING (auth.uid() = owner_id);
CREATE POLICY "items_delete" ON public.items FOR DELETE USING (auth.uid() = owner_id);

CREATE POLICY "bookings_select" ON public.bookings FOR SELECT
  USING (auth.uid() = renter_id);
CREATE POLICY "bookings_insert" ON public.bookings FOR INSERT
  WITH CHECK (auth.uid() = renter_id);
CREATE POLICY "bookings_update" ON public.bookings FOR UPDATE
  USING (auth.uid() = renter_id);

CREATE POLICY "owner_bookings_select" ON public.bookings FOR SELECT
  USING (EXISTS (SELECT 1 FROM public.items WHERE id = item_id AND owner_id = auth.uid()));
CREATE POLICY "owner_bookings_update" ON public.bookings FOR UPDATE
  USING (EXISTS (SELECT 1 FROM public.items WHERE id = item_id AND owner_id = auth.uid()));

CREATE POLICY "payments_select" ON public.payments FOR SELECT
  USING (EXISTS (
    SELECT 1 FROM public.bookings b
    WHERE b.id = booking_id
      AND (b.renter_id = auth.uid()
           OR EXISTS (SELECT 1 FROM public.items WHERE id = b.item_id AND owner_id = auth.uid()))
  ));

CREATE POLICY "reviews_select" ON public.reviews FOR SELECT USING (true);
CREATE POLICY "reviews_insert" ON public.reviews FOR INSERT
  WITH CHECK (auth.uid() = from_user_id);
```

## 4. Edge Function: create-rental-intent (актуальная)

**Путь:** `supabase/functions/create-rental-intent/index.ts`

**Логика ценообразования:**
```
rentalPrice     = price_per_day × totalDays
insuranceFee    = €3.00 × totalDays          ← €3/день страховка
platformFee     = rentalPrice × 12%          ← комиссия (не берётся с клиента)
deposit         = item.deposit
totalCharged    = rentalPrice + deposit + insuranceFee
```

**Что возвращает клиенту:**
```json
{
  "client_secret": "pi_xxx_secret_xxx",
  "amount": 4500,           // центы — то что списывается с карты
  "booking_id": "uuid",
  "insurance_amount": 900   // центы — для отображения в UI
}
```

## 6. Флоу аренды (Happy Path)

```
1. Home → фильтр по категории инструментов → карточка товара
2. ItemDetail → выбор дат в календаре
3. "Pay €X" → handleRent() → Edge Function create-rental-intent
   - проверяет даты на конфликты
   - создаёт booking (status: pending_payment)
   - считает: rental + deposit + insurance
   - создаёт Stripe PaymentIntent
   - возвращает { client_secret, amount, booking_id, insurance_amount }
4. <CheckoutForm> внутри <Elements stripe={stripePromise}>
5. Пользователь вводит карту → stripe.confirmPayment()
6. Успех → booking.status = confirmed → /my-rentals
7. Owner в MyItems видит бронирование → "Mark picked up"
   → booking.status = active
8. Owner → "Mark returned" → booking.status = completed
9. Renter оставляет отзыв (canReview = true когда status = completed)
```

## 11. Pro-подписка (реализовано)

### Как работает
- Пользователь заходит на `/pro`, нажимает "Start Pro"
- Edge Function `create-pro-checkout` создаёт Stripe Checkout Session (mode: `subscription`)
- После оплаты Stripe шлёт `customer.subscription.created` → webhook ставит `users.is_pro = true`
- При отмене: `customer.subscription.deleted` → `is_pro = false`
- В `create-rental-intent`: если `owner.is_pro = true` → `platformFee = 0` (0% комиссии)

### Stripe настройка (вручную в Dashboard)
1. Products → Create product: "RentIt Pro" → Price: €9.99/month recurring
2. Скопировать `price_id` → добавить в Supabase secrets: `STRIPE_PRO_PRICE_ID=price_xxx`
3. Webhook events добавить: `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`
4. Secrets: `supabase secrets set APP_URL=https://rentit.be`

## 12. Важные технические детали

- **Supabase join синтаксис:** `users!owner_id(...)` и `users!renter_id(...)` — чтобы различать FK на одну таблицу
- **Stripe:** `loadStripe(VITE_STRIPE_PUBLISHABLE_KEY)` вызывается один раз в `ItemDetail.tsx` — `CheckoutForm` только использует `useStripe()` / `useElements()`
- **Edge Functions:** Deno TypeScript. Service Role Key обязателен для bypass RLS
- **Комиссия:** 12% — не берётся с клиента, это доля платформы от выплаты владельцу. Хранится в `payments.platform_fee` для Admin аналитики
- **Страховка:** €3/день берётся с арендатора поверх стоимости аренды. Хранится в `bookings.insurance_amount` и `payments.insurance_amount`
- **Admin revenue:** суммирует `platform_fee + insurance_amount` по всем `succeeded` платежам
