Состояния брони

Построено по коду: RULES в transition-booking, плюс respond-to-request, request-rental и expire-bookings. Чего нет в правилах — запрещено: неизвестное сочетание отвергается, а не трактуется на усмотрение кода.

инвариант

Из «у локатора» выхода нет, кроме возврата

После handover бронь нельзя отменить: правила cancel существуют только для pending_approval и confirmed. Инструмент на руках — значит закрыть сделку можно лишь возвратом. Это не упущение, это решение: отмена того, что уже отдано, оставила бы вещь без состояния.

долг

Четыре статуса без единого пути

pending_payment, payment_expired, disputed есть в BookingStatusBadge, но недостижимы: функции Stripe с 11.08 из клиента не вызываются. Бейдж умеет рисовать состояния, в которые бронь не попадёт.
