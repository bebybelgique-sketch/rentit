Как витрина находит инструменты

Один запрос вместо выборки-и-фильтрации в браузере. Отбор по радиусу идёт ST_DWithin по GiST-индексу, занятость на даты исключается тут же. Глобального стора нет — состояние живёт в useState внутри Home.tsx.

почему функция, а не запрос

Список ид не влезает в адрес

Вариант «функция отдаёт ид, клиент подставляет их в .in(...)» упирается в длину URL на паре сотен вещей в радиусе. Такой фильтр работает ровно до первого успеха площадки.

права

Две разные причины

browse_items — INVOKER: политики на items продолжают действовать. items_busy_between — DEFINER, потому что посторонний не видит чужих броней и отфильтровать даты сам не может.

честно

Индекс пока не работает

На единицах строк планировщик берёт последовательный просмотр, и это правильно. GiST — отложенная польза, а не замеренное ускорение.
