# Пустая папка окружения для юнит-прогона

`vitest.config.ts` указывает сюда `envDir`. Файлов `.env*` здесь нет и быть
не должно — в этом весь смысл.

## Зачем

`src/lib/supabase.ts` БРОСАЕТ прямо при загрузке модуля, если нет
`VITE_SUPABASE_URL`. Это правильно: молча работать с пустой конфигурацией
хуже, чем упасть сразу.

Но Vite по умолчанию подхватывает `.env` из корня проекта, и на машине
разработчика переменная есть, а в CI её нет. Значит тест, забывший
заглушить `lib/supabase`, зеленеет локально и валит прогон в CI.

Так случилось ТРИЖДЫ: коммит 06d9ded, PR #75 и PR #95. Каждый раз
находка приходила из CI, а не с машины.

Теперь локальный прогон видит ровно то же, что и CI: ничего. Забытая
заглушка падает сразу, у себя, а не через десять минут на чужом сервере.

## Чего это НЕ меняет

Сквозные проверки (Playwright) читают `.env` сами, своим загрузчиком в
`playwright.config.ts` — им учётки нужны по-настоящему. Эта папка их не
касается.
