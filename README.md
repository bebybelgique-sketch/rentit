# RentIt

RentIt - это платформа для аренды инструментов между соседями.

## Особенности

- Поиск и аренда инструментов поблизости.
- Легкий способ сдать свои инструменты в аренду.
- Защита аренды.
- Поддержка нескольких языков (FR, EN, NL).

## Технологии

- React (TypeScript)
- Vite
- Supabase (Auth, Database, Storage)
- TanStack Query (ранее React Query) для управления состоянием и кэширования данных
- react-i18next для интернационализации
- react-hot-toast для уведомлений
- Testing Library и Vitest для тестирования

## Установка и запуск

1.  Склонируйте репозиторий:
    `git clone <URL_TO_THIS_REPO>`
2.  Перейдите в директорию проекта:
    `cd RentIt`
3.  Установите зависимости:
    `npm install`
4.  Скопируйте файл `.env.example` в `.env` и укажите свои ключи Supabase:
    `cp .env.example .env`
5.  Запустите проект в режиме разработки:
    `npm run dev`

## Деплой

Проект настроен для деплоя на Vercel. Просто импортируйте репозиторий в Vercel, и он автоматически использует `vercel.json` для настройки сборки и развертывания.
